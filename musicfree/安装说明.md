# MusicFree 插件 · DJ 舞曲合集 —— 安装与使用说明

适用版本：**安卓版 MusicFree** / **Windows 版 MusicFree Desktop**（插件通用 ✓）

文件：`musicfree/dj-plugin.js`（插件本体，约 15 KB）

---

## 一、安装方法

### 🪟 Windows 版（MusicFree Desktop）
1. 打开 MusicFree
2. 左侧栏点「**插件**」
3. 右上角「**+**」→ 选择「**导入本地插件**」/「从本地导入」
4. 选中 `dj-plugin.js`
5. 回首页搜索歌名即可（结果会带 `[清风DJ]`、`[多多DJ]` 等前缀）

### 📱 安卓版（MusicFree）
1. 先把 `dj-plugin.js` 传到手机（微信文件传输 / QQ / USB / 网盘均可）
2. 打开 MusicFree → 侧边栏「**插件**」
3. 右上角「**+**」→「**从本地导入**」→ 选中该 js 文件

### 🌐 或者用网址安装（两边都适用）
「插件」页面 → 「+」→「**从网络导入**」→ 填入下面的地址之一：

```
https://cdn.jsdelivr.net/gh/bai723172-cpu/gate@main/musicfree/dj-plugin.js
```
```
https://gh-proxy.com/https://raw.githubusercontent.com/bai723172-cpu/gate/main/musicfree/dj-plugin.js
```
> 说明：国内网络有时访问不到上面两个地址，此时请用「本地导入」方式 ✓

## 二、各站点支持情况（v0.4.0）

| 站点 | 搜索 | 播放 | 说明 |
|---|---|---|---|
| **清风DJ** ddddj.com | ✅ | ✅ | 详情页直接给出音频直链，稳定可用 |
| **多多DJ** duoduodj.com | ✅ | ✅ | 详情页里的 `KqDjurl` 即音频地址 |
| **呦呦DJ** djuu.com | ✅ | ✗ | 音频有**阿里云防盗链**（403），需站内播放器票据 |
| **82dj** 82dj.com | 🟡 | 🟡 | 搜索由 JS 渲染；完整曲目需**会员**（不会绕过） |
| **西西DJ** dj.net | 🟡 | 🟡 | GBK 站点，已做 GBK 解码；播放页无直链 |

> ⚠️ 只解析站点**公开免费试听**的音频 ✓
> **不做任何会员、付费、防盗链绕过** ✗ —— 播不了的部分插件会明确报错，而不是给一个失效地址

## 三、原理说明（为什么有的站不行）

1. **直链型（可做）**：详情页 HTML 里直接包含 `.mp3` 地址 → 清风DJ / 多多DJ ✓
2. **防盗链型（难做）**：音频地址需要带时效签名或播放器票据 → 呦呦DJ（阿里云 WAF `acw_tc` / `cdn_sec_tc`）✗
3. **会员型（不做）**：完整音频标记 `price=3` 之类 → 82dj ✗
4. **JS 渲染型（需逆向）**：搜索/播放地址由前端 JS 动态获取 → 82dj 搜索 / 西西DJ 播放 ✗

所有请求都走**直连**（这些站会屏蔽境外 IP，走代理反而会超时/报 SSL 错 ✗）

## 四、常见问题

**Q: 搜索没结果？**
A: ① 确认插件已启用（插件页里开关是开的）② 换个关键词试试 ③ 部分站点搜索依赖站点自身接口，偶尔会抽风，稍后重试

**Q: 能搜到但点了播放没反应 / 报错？**
A: 看该站点在第二节表格里的"播放"列 ✗ —— 标 ✗ 的站点音频受保护，插件拿不到合法地址

**Q: 结果里为什么带 `[清风DJ]` 这种前缀？**
A: 插件会同时搜索多个站点，前缀用来标明这首歌来自哪个站 ✓

**Q: 手机上要不要挂梯子？**
A: **不要** ✗ —— 这些站屏蔽境外 IP，必须用**本地网络直连** ✓（插件本身就是直连）
